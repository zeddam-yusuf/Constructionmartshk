# Construction Mart SHK

A modern, full-featured construction, interior renovation, and materials marketplace connecting clients, vendors, channel partners (Brokers, PMCs, Developers), and skilled laborers with real-time quotations, instant labour booking, verified listings, and AI-powered assistance.

---


## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Visualizations & Charts**: Recharts
- **Mapping**: `@vis.gl/react-google-maps`

---

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm, yarn, or pnpm

### Installation

1. Clone or download the repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd construction-mart
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Copy `.env.example` to `.env` and fill in any required keys:
   ```bash
   cp .env.example .env
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or the Vite localhost URL shown in the terminal) in your browser.

5. Build for production:
   ```bash
   npm run build
   ```

## 📁 Key Features

- **Multi-Role Portal**: Switch seamlessly between Client, Vendor, Material Supplier, PMC, Broker, Developer, Freelancer, and Labour profiles.
- **Direct Quotation Engine**: Auto-generate itemized quotations with PDF export and direct WhatsApp sharing.
- **Instant Labour Booking**: On-demand construction labor deployment with verification badges.
- **Material Rate Explorer**: Real-time regional pricing across cement, steel, sand, tiles, plumbing, and electrical.
- **AI Construction Assistant**: Instant technical Q&A, cost estimation, and project scoping.
